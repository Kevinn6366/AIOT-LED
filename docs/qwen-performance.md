# Qwen 全层 PL 性能实验

使用 ZYBO Z7-20、50 MHz 的 PL 矩阵核、64 位 AXI HP0、同一个 Q4_0 GGUF 和 ARM ELF。两种后端都运行在板上，PC 上的 Edge 负责输入和显示。

## 原位流的分段实测

诊断位流从 `b9ea48d` 的 Vivado 布线检查点生成，保留原核的状态机，使用周期寄存器的低 3 位观察状态。位 0 表示从发起一行权重的 HP0 读取到回到计算阶段；位 1 表示清零累加器、点积、缩放和部分累加；位 2 表示核空闲。最后的行归约、写回、激活读取和其余控制周期单独归入“其他”。权重读取阶段包含有效传输和等待。采样比例是时间占比估计。

板端 SDK 程序在已有的保留 DDR 中运行与模型等尺寸的矩阵，随机化采样间隔。仅覆盖输出暂存区。各行使用实际内核，输入数值不影响这些固定形状循环的分支。空调用测试做 1,000 次参数写入、启动和完成轮询，合计 176,216 个 50 MHz 周期，平均 3.52 微秒。它测量主动轮询的固定开销；应用对大矩阵还会休眠轮询。

| 矩阵（输入宽 × 输出行，列数） | 权重读取 | 算术 | 其他及空闲 |
| --- | ---: | ---: | ---: |
| Q4 查询（896 × 896，2） | 11.57% | 81.00% | 7.43% |
| Q4 FFN 上投影（896 × 4864，2） | 11.61% | 80.95% | 7.43% |
| Q4 FFN 下投影（4864 × 896，1） | 10.34% | 88.03% | 1.63% |
| Q8 词表输出（896 × 151936，1） | 16.43% | 76.56% | 7.01% |
| FP 注意力样本（64 × 64，1） | 22.79% | 47.39% | 29.82% |

同一道灯题从首个到最后一个活跃样本，共 121,933 次采样。算术占 79.35%，读取权重行占 12.22%，核空闲占 2.21%，其余占 6.22%。核空闲含 PS 调度、激活处理和采样，因此 2.21% 不能全部计为调用开销。该次网页首字 161.31 秒、生成 0.09689 token/s，与原位流的两轮记录一致到百分之一以内。[阶段原始计数及同题回包](qwen-phase-samples.json)

复测时在仓库根目录用 Vivado 执行 `hardware/qwen/profile-baseline.tcl`，输入检查点须由原提交生成。用 SDK 的 ARM Linux GCC 以 `-O2 -static` 编译 `tests/qwen_profile.c`。在维护窗口暂停访问 PL 的板端进程，用 FPGA Manager 加载诊断位流。运行采样程序取得上表；恢复应用后，用其 `sample` 模式旁路采样，再运行 `python tests/compare_qwen.py --sample-baseline` 取得整道题的分布。采样器首先校验空闲标志，正式位流的周期寄存器仍使用完整的 32 位计数。

## 修改

原核每次读完一行，再逐块计算，每块分四次取激活。新核按最多 64 行连续读取 DDR，用 FIFO 连接取数、权重拼装和点积。每个块的 32 个整数乘法展开，两列激活使用独立分区，缩放与行累加在流水线中执行。HLS 综合得到取数每周期一字，量化点积的启动间隔为 3 周期。量化格式、时钟、两列接口、PS 调度和纯 PS 对照保持相同。

## 两列流水核的网页结果

固件 `5a91857fe6c1` 在 B 槽启动。Vivado 实现占用 31,033 个 LUT、54 个 BRAM Tile、140 个 DSP；WNS 2.854 ns、WHS 0.016 ns。两轮均算 42 个提示 token、生成 17 个 token，回答完全相同。PL 两轮首字均为 29.33 秒，速度为 0.54286、0.54263 token/s；纯 PS 两轮首字均为 24.29 秒，速度为 1.06088、1.05946 token/s。相较原 PL，首字耗时降至约 18%，生成速度提升至约 5.6 倍。两列版本的首字仍比纯 PS 慢 5.04 秒。[四次网页请求的原始结果](qwen-two-column-comparison.json)
